# 技能目录

按当前任务选择技能。同一技能可用于多个阶段，目录保持 `skills/<name>/`。下表区分通用产品方法、依赖业务模式的方法与平台专项；具体工具和执行范围以技能入口为准。

## 发现、验证与定位

| 技能 | 任务 | 适用范围 |
|---|---|---|
| [find-product-opportunities](../skills/find-product-opportunities/SKILL.md) | 从行业、受众与变化中寻找产品机会 | 各类软件产品 |
| [validate-product-idea](../skills/validate-product-idea/SKILL.md) | 验证已有想法，选择形态与首版范围 | 各类软件产品 |
| [customer-research](../skills/customer-research/SKILL.md) | 访谈、评论、问卷与用户任务研究 | 跨形态，按可获得证据选方法 |
| [competitor-profiling](../skills/competitor-profiling/SKILL.md) | 研究竞争产品、替代方案与定位 | 有可核查来源的竞争对象 |
| [product-marketing](../skills/product-marketing/SKILL.md) | 建立产品、受众、定位与品牌语气上下文 | 跨形态；需要持久化上下文时使用 |
| [pricing](../skills/pricing/SKILL.md) | 定价、包装与收费方式 | 按买断、订阅、用量等实际模式选择 |
| [marketing-psychology](../skills/marketing-psychology/SKILL.md) | 分析购买决策与表达方式 | 跨形态 |
